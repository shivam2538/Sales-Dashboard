# 🛒 Blinkit Sales Dashboard | Power BI



## 📌 Project Overview

The **Blinkit Sales Dashboard** is an interactive Power BI project developed to analyze sales performance, customer purchasing behavior, product trends, and outlet performance. The dashboard enables stakeholders to make data-driven decisions through visually rich insights and KPI tracking.

## 📊 Key Performance Indicators (KPIs)

| KPI              | Description                     |
| ---------------- | ------------------------------- |
| 💰 Total Sales   | Overall revenue generated       |
| 🛒 Total Orders  | Number of orders processed      |
| 📦 Items Sold    | Total quantity sold             |
| ⭐ Average Rating | Customer satisfaction score     |
| 📈 Average Sales | Average revenue per transaction |

## 🧮 DAX Measures Used

```DAX
Total Sales =
SUM(Blinkit[Sales])

Total Orders =
COUNT(Blinkit[Order_ID])

Average Sales =
AVERAGE(Blinkit[Sales])

Average Rating =
AVERAGE(Blinkit[Rating])
